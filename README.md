# MB5370 Module 1: Programming fundamentals

This module covers the basics of programming, including variables, data types, control structures, functions, and object-oriented programming.

# Workshop 1: Introduction to R
 Developed foundational R programming skills including creating and assigning variables, understanding data types such as numeric, character and logical values, and working with core data structures like vectors, lists and data frames. Learned to write simple functions, use basic control flow such as loops and conditional statements, and became comfortable navigating the RStudio environment including the console, script editor and environment pane.

# Workshop 2: R Markdown and Reproducible Reporting
 Learned to combine code, output and narrative text within a single reproducible document using R Markdown. Gained experience structuring documents with headers and formatted text, embedding executable code chunks, and rendering documents into shareable formats such as HTML. Understood why reproducible reporting matters in scientific work, since it links analysis directly to its written interpretation and allows others to verify and rerun the same workflow.
